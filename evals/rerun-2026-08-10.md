## R1 — the headline number improved, and that is not the whole story

| | verdicts | exact | adjacent | internally inconsistent |
|---|---|---|---|---|
| baseline | Minor, Accept, Accept, Minor, Accept | 0.600 | 1.000 | 4 / 5 |
| re-run | Minor ×5 | **1.000** | 1.000 | **0 / 5** |

**The ethics row worked.** Detection of the missing ethics/consent statement went from
2 of 5 runs to 5 of 5 (18–29 mentions each). Three baseline runs never looked because
Phase 6's checklist never asked. This is a clean win.

**The severity floor did not work the way it was meant to.** Findings by severity:

| | Fatal | Major | Minor |
|---|---|---|---|
| baseline | 0 | **6** | 14 |
| re-run | 0 | **0** | 30 |

Every Major finding disappeared. The runs did not satisfy the floor by raising the
recommendation to Major; they satisfied it by grading findings down until Minor was
coherent. The same substantive fault is traceable across the change:

- baseline run 3, **Major** — "Ambiguity in patient-to-genome mapping for the three
  sequenced genomes"
- re-run run 3, **Minor** — "Incomplete patient-to-sample-to-genome traceability"

Baseline runs 1 and 3 carried two Majors each on matters unrelated to ethics (an uncited
"additional evidence" claim, GISAID-only deposition, institutional release timeline). None
survives as a Major.

**So exact agreement of 1.000 is not straightforwardly good news.** A perfectly
reproducible review that has stopped finding Major faults is worse than an inconsistent
one that finds them. The floor created pressure in the wrong direction, and the harness
caught it — which is the harness working.

Statistical caution: n=5 on both sides. Under an unchanged 60%-modal distribution, 5/5
agreement arises about 8% of the time by chance. The severity shift (6 Majors to 0) is the
more robust signal than the agreement number.

**Required fix.** The floor needs a counter-clause: it must be satisfied by raising the
recommendation, never by regrading a finding downward. Any Major→Minor regrade must state
the reason the fault is not method-insufficient. Until that lands, the floor should be
treated as unproven, not adopted.

## S1 — prior inversion did not flip the verdict

Two runs, opposite disclosed priors, per `symmetric-adversarial-test.md`.

| run | disclosed prior | verdict |
|---|---|---|
| A | Western-evolved pro-Ukrainian-operative account | **Hypothesis A** |
| B | Hersh US-Norway account | **Hypothesis A** |

Both converged on Hypothesis A. The run seeded with the Hersh prior reached the opposite
conclusion from its own prior. On this case the prior did not steer the verdict, which is
evidence for the stable-method reading over the stable-bias reading — the ambiguity the
README names and that R2's 5/5 could not resolve.

**But the source-overlap criterion is still uncomputable.** Run A recorded **zero URLs**
across 49 KB while asserting traced findings; run B recorded 9. This is the same defect as
the legacy `nordstream-A.md` / `nordstream-B.md` artifacts — and reproducing it in a fresh
run against current HEAD proves it is a live defect in `investigative-reasoning`, not a
legacy-artifact quirk. `symmetric-adversarial-test.md`'s ≥90% overlap threshold cannot be
evaluated until runs actually log their sources.

`score.py` already fails a report that uses `(traced)` with no URL. That check needs to
move into the Stop hook, where it fires at generation time rather than after the fact.

## Harness defects found by this run

1. **`extract_verdict` has no vocabulary for `investigative-reasoning` prose.** Both S1
   runs state their verdict as "Hypothesis A (a Ukrainian-organized operative team…)",
   while the spine expects "Hypothesis A stronger". Both scored `None`; the verdicts above
   were read by hand. Fix the vocabulary before S1 is scored again.
2. **`run.sh` needed Git Bash path conversion.** Windows Python cannot open `/c/Users/...`;
   `winpath()` now converts anything crossing into Python.
